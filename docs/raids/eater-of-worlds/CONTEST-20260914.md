# Eater of Worlds Contest launch

The Raids page offers **Standard** and **Contest** for Eater of Worlds. Contest changes only the player's effective Power. Enemy types, counts, perception, firing behavior, mechanics, doors and rewards use the same encounter implementation in both modes.

See [native package evidence](NATIVE-PACKAGE-MAP.md). Contest caps the selected player's effective Power at **730**. A character already below 730 is not raised. The selected equipped items are projected to level 73 (10 Power per level); stored inventory and unequipped/profile candidates retain their original values.

The mode is copied into the launch request. It is armed only after the native descriptor, opening support and destination validate, immediately before native selection. A stale pre-launch world cannot consume the pending session binding. A confirmed new Eater session binds it; retries in that session retain it. Orbit, failed launch, timeout, wrong destination, an unrelated session and a subsequent Standard launch clear it. Contest does not activate Nightfall equipment locks, limited revives, movement restrictions or reward rules.

Power publications use the existing character/equipment, item, roster and banner paths. Full Family-4 snapshots share one captured projection between character and equipped items. An initial subscription burst pins one projection across its roster, Family-4 companion and banner. A failed Power refresh cannot fall through to lower-priority account images, while independent activity keepalives remain available.

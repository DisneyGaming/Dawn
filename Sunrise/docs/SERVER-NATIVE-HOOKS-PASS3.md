# Native hook migration, third pass

This pass implements additional native server-to-client authority in the compiled mission paths. It does not make every remaining behavior native. Two agents assisted; the third stayed interrupted as requested. The user authorized all feasible replacements and installation; no new manual approval requirement was introduced.

## Newly native in the active implementation

- Panoptes left/right arm raising and release through native member scalar authority.
- Panoptes intro, crown summon and all three combat animation programs through native member queues.
- All four Panoptes chase departures and the final relocation through the native targeted-program producer and original authored curve, with actual native movement acknowledgement.
- Garden World platform travel, phase rebase, parking, return and death freeze through native type23 position commands.
- Omega and both Beyond Infinity Forest seed, anchor, enable and topology requests through native type37. Garden's topology selection uses the same recovered native fields. The FF2F80 solver detour and automatic worker/source recipe writes are removed.
- A Deadly Trial and Hijacked dialogue row delivery through their actual native dialogue bodies; duplicate row-buffer repairs are removed.
- A Deadly Trial and Hijacked objective installation, replacement, target references, display mode and retirement through native type68. Read-only readiness observations prevent loading from consuming an objective prematurely; native ring rotation retries a replacement without changing authored variant indices.

The dormant experimental first-Forest portal request and polling adapter were also deleted. It had no executable request caller. Existing active membership-based portals were already native; deleting that adapter is cleanup, not a new transport migration.

The prior plate preparation fix, native capture timers and pose delivery, Omega arc-charge receptacle enabling and Trial pedestal enabling remain included. The pass-two arm claim was incorrect because it targeted unused legacy code; this pass changes the compiled cinematic owner, server runtime, projection and archive encoder.

## Still requires client adapters

- Synchronous damage/immunity and boss, cube, module or lens protection. The server does not yet decode the external simulation entity/damage transaction protocol.
- Remaining Panoptes eye/provider, targeting, scoped attack-event and child-lifetime operations. Native variable rows do not reproduce the upstream provider setter or event-reference ownership.
- Garden World attack/target/shield/tether presentation and related actor corrections. Its anomaly candidate does not contain a beam alternative, and the source placement override only carries XYZ.
- Hijacked boss movement. Its member receiver exists, but its authored destinations are type47 points; the native queue accepts type48/58 paths. Original resolver tests reject points, and the full299-asset catalog has no suitable boss path.
- Selective shield/model visibility, Ikora/Panoptes VFX, custom waypoint positions, local placement, streaming unloads and child cleanup.
- Cross-activity ending selection/classification and cinematic handoff. Current group hosting owns a public-region session, not the primary fireteam session required by the native ending property. The original cinematic suppression predicate is a constant-false function, not a configurable server field.
- Revival binding, roster/bootstrap compatibility, Forest owner-authority bitmap repair, spawn holds and fade release. Explicit diagnostic Forest controls remain available but default off.

These adapters remain active to retain mission behavior. No client engine call moved onto a server thread, renamed helper or unused codec is counted as a migration. Replacing these boundaries requires additional protocol or authored-content support, rather than removing their current calls.
